# Activity 1

# Project Title 
Volt Vault

# Description
This landing page showcases an online shop called Volt Vault, designed to present modern technology products in a clear and attractive layout. It is intended for users who are looking for gadgets, accessories, and smart devices in one convenient place. The page highlights the brand, features, services and product categories to guide visitors easily through the site. Its purpose is to create a strong first impression and encourage users to explore and shop.

# Technologies Used
- HTML
- CSS

# Features
- Hero section with call-to-action button
- Feature boxes highlighting About, Features, and Services
- Gadget categories section for easy product browsing
- Animated background and hover effects
